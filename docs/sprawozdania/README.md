# Sprawozdania cząstkowe

Po każdym etapie dodajemy tu krótkie sprawozdanie (1–2 strony), które oddajemy prowadzącemu. Sprawozdanie końcowe (`docs/sprawozdanie-koncowe.md`) składamy z tych plików.

| Plik | Etap |
|---|---|
| `etap-1-2.md` | Etapy 1 i 2: inwentaryzacja, DFD, Purdue, Zones & Conduits, SL-T |
| `etap-3.md` | Etap 3: bezpieczeństwo komunikacji MQTT |
| `etap-4.md` | Etap 4: modelowanie zagrożeń i incydent |
| `etap-5.md` | Etap 5: Edge AI i detekcja anomalii |

## Szablon

```markdown
# Etap N — <nazwa>

Data: RRRR-MM-DD

## Cel
Co etap miał dać, według instrukcji.

## Co zrobiliśmy
Najważniejsze decyzje i kroki, z linkami do plików w repozytorium.

## Dowody
Tabele, schematy, zrzuty, pcap i logi z `evidence/etap-N/`.

## Wnioski
Co z tego wynika dla kolejnych etapów.

## Problemy i ograniczenia
Co nie wyszło albo co upraszczamy względem rzeczywistości.
```
